# 📘 Personal Result Tracker

A modern and responsive **Personal Result Tracker** built using **HTML, CSS, and JavaScript**.
This project helps students manage course results, calculate GPA automatically, and monitor overall CGPA with a beautiful interactive interface.

---

# ✨ Features

* 📚 Add course results easily
* 🧮 Automatic GPA & CGPA calculation
* 🎨 Dynamic CGPA color indicators
* 📊 Grade-based row highlighting
* ✏️ Edit existing results
* 🗑️ Delete results instantly
* 💾 Local Storage support (data saved automatically)
* 📱 Fully responsive design
* 🌈 Modern UI with animations and glowing effects

---

# 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Local Storage API

# 🧠 GPA Calculation System

The application automatically converts total marks into grades and GPA.

| Marks Range | Grade | GPA  |
| ----------- | ----- | ---- |
| 80 - 100    | A+    | 4.00 |
| 75 - 79     | A     | 3.75 |
| 70 - 74     | A-    | 3.50 |
| 65 - 69     | B+    | 3.25 |
| 60 - 64     | B     | 3.00 |
| 55 - 59     | B-    | 2.75 |
| 50 - 54     | C+    | 2.50 |
| 45 - 49     | C     | 2.25 |
| 40 - 44     | D     | 2.00 |
| Below 40    | F     | 0.00 |
